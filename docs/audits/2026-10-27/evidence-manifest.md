## Inspection, redaction and exclusions

- The original `VAYLET_AUDIT_EVIDENCE.zip` is **not published** because it duplicates all65 individually published members and contains unsanitized local host paths and synthetic URL userinfo. Its original hash is recorded above.
- Host-specific workspace, dependency, runtime and cache prefixes are replaced by symbolic aliases in documentation/logs. Repository-relative paths, code line references, result values, confidence and outcomes are retained.
- Two occurrences of synthetic credential-shaped URL userinfo in Customer test-title metadata are replaced with `[REDACTED_SYNTHETIC_USERINFO]`. They were unsafe-origin test fixtures, not real credentials. No password/userinfo value is published.
- Reproduction/configuration evidence replaces machine-specific paths with `reproduction-paths.cjs`. Only path/dependency selection changed; no model, assertion or outcome was strengthened. Scripts were not rerun for publication.
- No factual evidence member was omitted. Empty logs remain empty and are explicitly qualified. Raw/private GitHub issue dumps, shared dependency caches, application source trees and unrelated local scratch files were never members and are not added.
- No screenshots, actual provider/device evidence, real customer data, database dumps, environment files, sensitive production logs, keys/tokens/cookies or credentials were found in the inspected archive. Their absence is not evidence that missing qualification occurred.
