## Real viewport evidence

Run `node capture-reference.mjs` from this folder (Node 22+, installed Microsoft Edge). It creates local screenshot and bounding-rectangle JSON pairs using the Chromium Debugging Protocol (`Emulation.setDeviceMetricsOverride`) so **CSS viewport widths and screenshot pixel widths match**. Plain Edge `--window-size=320,800 --screenshot=...` was rejected: it silently used a 492px CSS viewport and clipped the screenshot to 320px. All valid screenshots below were regenerated by CDP at the exact viewport width.

All five runs asserted **exactly four original KPIs**, **exactly two original chart panels**, CSS viewport width equals screenshot width, and no document horizontal overflow.
