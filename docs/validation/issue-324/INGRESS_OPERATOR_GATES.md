## Reading the status

- **SOURCE CONTROLLED** means behavior is present in the candidate source at the pinned SHA. It does **not** prove a particular artifact is deployed or that an external intermediary preserves the behavior.
- **SOURCE TESTED** additionally means a local test exercises that precise behavior. A unit or loopback Nest HTTP test is not an Internet-edge test.
- **OPERATOR UNKNOWN** means the effective deployed value, public response or network boundary was not inspected. It is an acceptance gate, not a finding that a production control is absent.
- **NOT DEFINED IN SOURCE** means there is no production configuration in this checkout proving the requirement; a separately managed provider/host configuration may still implement it.

## Operator evidence packet — required before marking ingress closed

An authorized environment owner should return the following **redacted, dated, environment-specific** packet. Use a staging environment first where meaningful, and separate staging from production in the acceptance record:

1. **Release identity:** public hostname → service/replica → immutable artifact digest and `VAYLET_RELEASE_GIT_SHA` (where deployed), plus build config version and runtime `NODE_ENV`. Match the exact SHA under review; a passing source test for `b8fcf4d5` cannot attest a different running commit.
2. **Network map:** DNS and Cloudflare zone/tunnel ingress rules, TLS termination and authenticated origin hop, actual reverse proxy (if any), listeners and ACLs, health routes, Native API route, API direct-origin denial and owner of each edge. Include the effective `ANTI_ABUSE_TRUSTED_PROXY_CIDRS` **without secrets** and a peer-by-peer trust explanation.
3. **Unauthenticated response sample for each exposed host:** HTTPS document/404/static route as applicable; API success/denial/doc endpoints if an API host is actually exposed; status, final URL, redirects, certificate metadata, HSTS, CSP, frame/MIME/referrer/permissions/cache headers, and absence of X-Powered-By. Include HTTP→HTTPS behavior. Do not attach request Authorization, Cookie, Set-Cookie values, guest links, or authenticated bodies.
4. **Controlled authentication transport test:** after operator approval, perform valid and rejected Guest/Staff Origin/CSRF checks via their real same-origin rewrites. Record only status/classification, cookie attribute flags/paths and whether browser accepted the cookie. Redact all cookie values, tokens, passwords, OTPs and visit IDs.
5. **Forwarded header/abuse proof:** from controlled trusted and untrusted paths, verify client-supplied forwarding headers are removed or overwritten, duplicates/malformed chains fail closed where used, direct API bypass is denied, expected limiter identity is stable, and monitoring does not record private credentials.
6. **OCR egress owner evidence:** endpoint HTTPS policy and certificate/redirect behavior, approved provider domain, credential scope and ownership, no plaintext token/image logging; only sanitized config metadata. This proves deployed egress configuration, whereas source tests prove endpoint validation.
7. **Signoff record:** environment, collection date/time, evidence links in restricted storage, operator name/role, edge policy revision, pass/fail for each matrix row, gaps and owner-approved next action. Do not paste screenshots showing secrets into this repository.
