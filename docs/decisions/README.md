# Focused Decisions

Focused decision files in this directory hold the complete contract for material repository decisions that need more detail than the canonical summary in `docs/08_DECISIONS_LOG.md`.

A file is binding only when its own status is `Accepted`, as defined by `AGENTS.md` and `docs/00_SOURCE_OF_TRUTH.md`.

When a focused Accepted DEC also has a summary entry in `docs/08_DECISIONS_LOG.md`, the focused file is the full contract and the log entry is the canonical summary/index. Material conflicts must be reconciled before implementation.

A temporary summary-mirror lag does not make an already merged focused Accepted DEC non-binding; it should be repaired in a documentation-maintenance task and must never be used to reinterpret the accepted contract.
